Formatting
  • **bold** prints bold, and {{i|text}} prints italics — braces rather than *asterisks*, because abilities put a lone * through half the wiki (“Each night*”)
  • {{blue|Undertaker}} prints the name in good blue
  • {{red|Imp}} prints it in evil red
  • Every team has its own mark: {{townsfolk|…}} blue, {{outsider|…}} teal, {{minion|…}} rust, {{demon|…}} red, {{traveller|…}} half and half, {{fabled|…}} gold, {{loric|…}} green
  • [[Snake Charmer]] links to that character — to the official wiki if it is one of the game’s own, to their page here if it is one of ours, and otherwise it prints a reminder token
  • [[Drunk]] prints a reminder token instead, whenever the name is one of this character’s own reminder tokens — and a name in ALL CAPS ([[UNDEAD]]) is always a token, never a link, wherever it appears
  • [the rules](https://example.com) links anywhere you like
  • {{drop|T}} at the start of a paragraph makes a big almanac drop cap out of that one letter
  • They combine: {{red|[[Imp]]}} is a red link to the Imp, {{i|{{red|Imp}}}} a red italic name (either way round), and {{red|{{drop|T}}}} a red drop cap — that one that way round only
  • The Ability box takes none of these — it is the character’s rule, printed verbatim on tokens, exports and cards

Special properties

The behaviour flags the official script tools read — whether the character can be drawn from the bag, what the app shows the Storyteller, and so on. Most characters need none. The Drunk and the Phantom, for instance, both carry ability / bag-disabled. Imported characters keep whatever they arrived with.
